# Cover-text B34 — только JSON

Выход: один JSON-объект, без markdown и без пояснений.

## Сюжет
Новостройки / дом по подряду под Тюменью. Семья остановила перевод: в договоре нет счёта эскроу, только реквизиты фирмы. Эскроу на частный дом по 186-ФЗ не обязателен. Около 600 домов в области уже построены со счётом.

## Hook
- ОДНА строка, 5–7 кириллических слов, не длиннее 56 символов.
- Минимум два слова длиной от 5 букв.
- Без латиницы. Без «аванс», «ЕГРН», «ДКП», «дарственная».
- highlight — одно слово из hook.
- sticky — до 5 слов, короткая реакция, до 32 символов.

## wordstat_stickers
Ровно 2 фразы, кириллица:
- строительство домов в тюмени
- счет эскроу

## inline_labels
Ключи inline_1 … inline_7. На каждой панели 3–5 коротких строк, 1–4 слова, до 28 символов, только кириллица и цифры. Факты из статьи:
- около 600 домов
- 1,5 тысячи договоров
- эскроу не обязателен
- реквизиты фирмы
- счёт открывает заказчик
- выплата после приёмки
- закон 186-ФЗ
- с 1 марта 2025
- 1441 договор в августе
- 581 сданный дом

На inline_1, inline_2, inline_4 сделай подписи как контекст фото (офис, договор, участок), не слоганы. Остальные — схемы с цифрами.

## meme_picks
Только id из каталога. Люди + кот, не только коты.
Запрещены за 14 дней: hide_pain_harold, smudge_cat, disappointed_black_guy, this_is_fine_dog, roll_safe, grumpy_cat, two_buttons, crying_cat, confused_math_lady, cheems.
Запрещены навсегда: drake, drake_no_yes, salt_bae, stock_handsome_man.
Используй ровно:
- cover: side_eye_chloe и polite_cat
- inline_1: disaster_girl
- inline_5: blinking_white_guy
- inline_7: doge
