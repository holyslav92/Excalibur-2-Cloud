# Один проход Sol

Верни целиком тот же HTML. Без markdown и без отчёта.

Поправь только это:
1. В первых двух предложениях лида оставь число 600 и добавь слово «остановила» или «остановили». Смысл прежний: семья не перевела деньги фирме.
2. Добавь несколько длинных тире там, где уже есть пауза. Факты не меняй.
3. Не используй слова: аванс, дарственная, ЕГРН, ДКП, выселение, квартирант, семейная ипотека, переуступка.
4. Если текст короче 1400 слов, чуть разверни сцену в офисе без новых цифр, имён и адресов. Потолок 1580.
5. Сохрани ссылки, классы CTA, телефон один раз и вопрос для комментариев.
