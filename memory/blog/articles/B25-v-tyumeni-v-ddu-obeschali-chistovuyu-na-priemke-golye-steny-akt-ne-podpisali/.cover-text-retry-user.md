## Правила

- hook: 5–7 слов, простой русский, не копировать H1 дословно. Пример формы: «На приёмке голые стены вместо чистовой»
- highlight: одно слово из hook
- sticky: короткая реакция, до 5 слов
- phone_cta: ровно +7 922 001 65 05
- inline_labels: 2–6 подписей на каждый inline_1…inline_7, каждая 1–4 слова, только кириллица
- НЕ включать wordstat_stickers
- meme_picks cover: 1 people + 1 cat из meme-top100.json
- Запрещённые meme id: drake, drake_no_yes, salt_bae, stock_handsome_man
- Anti-repeat 14д — НЕ использовать: hide_pain_harold, smudge_cat, roll_safe, crying_cat, blinking_white_guy, polite_cat, bad_luck_brian, grumpy_cat, two_buttons, surprised_tom, disaster_girl, keyboard_cat, side_eye_chloe, pop_cat
- Допустимые примеры: james_doakes, long_cat, confused_math_lady, this_is_fine_dog, wojak, cheems, doge, disappointed_black_guy, sacrednik_priest, capybara_indifference

## Факты для inline_labels

inline_1: реклама «под ключ», приложение к ДДУ, пол/стены/сантехника/двери
inline_2: white box, стены без финиша, пол — стяжка, санузел без плитки, три расхождения
inline_3: «доделаем потом», передаточный акт, акт осмотра, устное обещание
inline_4: акт не подписан, фото и видео, односторонняя фиксация, претензия письмом
inline_5: 214-ФЗ, лимит 3%, 60 дней, заказное письмо
inline_6: пол с покрытием, стены с отделкой, санузел с плиткой, по приложению
inline_7: сверка перечня, расхождения до подписи, не начинать ремонт, консультация до акта
