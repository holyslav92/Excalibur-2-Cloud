# Article style — язык и форма статьи

Правила языка и формы для Title / Writer / Sol.
Живой ритм подачи — в:

1. `shared/SOUL.md`
2. `shared/soul-examples/good-outputs.md`
3. `shared/soul-examples/post-to-article.md`
4. `shared/soul-examples/bad-outputs.md`

Язык тенанта: **русский** (`tenant-config.language=ru`).

## Голос

- Личный риэлтор: «я», «веду сделку», «проверяю до аванса». Не агентство, не «мы менеджеры».
- Прямой, ясный. Спокойный эксперт. Без корпоративной воды и SEO-штампов.
- Одна мысль за раз. Если абзац можно сократить — сокращай.
- Мнение автора уместно («не сравнивайте только проценты»), факты не выдумывай.
- Лёгкая ирония через факт. Без стендапа и без унижения сторон сделки.
- Форматы: разбор риска, чеклист, troubleshooting, сравнение тарифов (если дал Writer).

## Русский язык

- Избегай англицизмов, когда есть русское слово. Имена продуктов и законов оставляй как в источнике Writer (ДДУ, ЕГРН, эскроу).
- Допустимы оба написания **риэлтор / риелтор** как у тенанта (сайт и Дзен); не плоди третье («риелторъ»).
- Без канцелярита: «данный», «осуществлять», «является», «в рамках», «объект недвижимости мечты».
- Без штампов: «в современном мире», «как известно», «давайте разберёмся», «полный гайд».
- Без плашки терминов / глоссария в лиде.
- Без эмодзи в тексте статьи.

## Заголовок (H1)

- Одна конкретная мысль или конфликт (цена ошибки, документ, который не подняли).
- Без SEO-хвостов: «полный гайд 2026», «за вечер», «без копипаста», «риэлтор Тюмень купить квартиру».
- Без обещания нулевого риска и без «лучший риэлтор».
- Короткий, живой. Не шаблон серии («Часть 12: маткапитал снова»).
- Для Дзена: прямой порядок слов, без кликбейта и оценки как факта — см. `shared/dzen-content-rules.md`.

## Открытие

- Sol владеет финальным открытием в `article.html`.
- Сразу: сцена или ставка + зачем читать (метод до аванса). Затем TL;DR / «Быстрый инсайт».
- Без research-брифинга.

## Структура

- H2 = бит проверки или место, где теряют деньги.
- Нумерованные чеклисты с глаголами.
- Таблицы — для сравнения условий/сторон оплаты, не для «контента ради SEO».
- В финале уместны: предел компетенции, «Материал проверен: Святослав Шакин…», дисклеймер «не заменяет индивидуальную юрконсультацию».

## Мат

- `dzen_rf_pack=true` — **мат запрещён полностью**, в том числе с заменой символами.
- См. `shared/dzen-content-rules.md`.

## CTA

- Только ссылки из `shared/tenant-config.json` → `cta_links`.
- Сейчас единственная: `https://t.me/Tyumen_Rieltor`.
- `cta_required=false`, но если ссылка в списке — гейт ждёт её в HTML: поставь **один** раз после пользы (финал или короткий блок консультации).
- Не interlink на старые статьи (`interlink_old_articles=false`).
- Телефон, VK, канал, WhatsApp из site-brief **не обязаны** быть в каждой статье и не заменяют cta_links.

## Запреты площадок

- Не делать героем how-to VPN, обход блокировок, Instagram/Facebook/Meta и другие RF-blocked сущности.
- Разрешённые каналы упоминать нейтрально, если Writer дал факт; продвижение — через CTA тенанта.

## Self-check

1. Лид звучит как живой риэлтор у сделки, не справочник?
2. Нет термин-дампа в первых 2 предложениях?
3. Есть метод проверки и нет обещания нулевого риска?
4. H1 без SEO-хвоста и без «лучший в Тюмени»?
5. CTA только Telegram из tenant-config, не в каждом абзаце?
6. Мата и эмодзи нет?
7. Любое слово можно заменить проще? Замени.
