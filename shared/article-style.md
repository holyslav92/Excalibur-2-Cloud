# Article style — язык и форма статьи

Правила языка и формы для Title / Writer / Sol.
Живой ритм подачи — в:

1. `shared/SOUL.md`
2. `shared/soul-examples/good-outputs.md`
3. `shared/soul-examples/post-to-article.md`
4. `shared/soul-examples/bad-outputs.md`

## Голос

- Прямой, ясный. Без корпоративной воды и без SEO-штампов.
- Одна мысль за раз. Если абзац можно сократить — сокращай.
- Мнение автора важнее нейтральности, но факты не выдумывай.
- Конкретика тенанта (тон, ирония, длина) — после Setup Voice.

## Русский язык (если language=ru)

- Избегай англицизмов, когда есть русское слово. Продуктовые имена оставляй.
- Без канцелярита: «данный», «осуществлять», «является», «в рамках».
- Без штампов: «в современном мире», «как известно», «давайте разберёмся».
- Без плашки терминов / глоссария в лиде.

## Заголовок (H1)

- Одна конкретная мысль или конфликт.
- Без SEO-хвостов («полный гайд 2026», «за вечер», «без копипаста»).
- Короткий, живой. Не шаблон серии.

## Открытие

- Sol владеет финальным открытием в `article.html`.
- Сразу: о чём речь и зачем читать. Без research-брифинга.

## Мат

- По умолчанию для Дзена (`dzen_rf_pack`, см. `shared/dzen-content-rules.md`) — **мат запрещён** полностью.
- Иначе — только если SOUL/тенант явно разрешил и с правилами маскировки из Setup.

## CTA

- Только ссылки из `shared/tenant-config.json` → `cta_links`.
- Если `cta_required=false` и список пуст — CTA в тексте не обязателен.
- Не interlink на старые статьи, если `interlink_old_articles=false`.

## Self-check

1. Лид звучит как живой человек, не справочник?
2. Нет термин-дампа в первых 2 предложениях?
3. Любое слово можно заменить проще? Замени.
