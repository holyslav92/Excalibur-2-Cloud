# Post → article

Как из короткого слога (Дзен-пост, лид сайта) собрать longread блога.

## Канон сборки

1. **Не копипаст** одного поста на весь `article.html`.
2. Статья = цепочка **битов** под H2. Каждый бит: тезис → уточнение → сцена или шаг проверки → удар (вердикт) → короткий финал.
3. **Факты, цифры, тарифы, нормы, URL** — только из `drafts/writer.html` / research. Слог подставляет ритм, не выдумывает закон.
4. Лид без research-даты, без Wordstat, без глоссария.
5. H1 берётся из `title-brief.json` (Title). Sol не приделывает SEO-хвост.

## Каркас под тенанта

| Часть | Что делать | Чего не делать |
| --- | --- | --- |
| Лид | Сцена риска или цена ошибки на сделке | «В этой статье», перечень терминов |
| Представление | Один раз: Святослав Шакин, риелтор в Тюмени (на зеркале Дзена уместнее явно) | Повторять ФИО в каждом H2 |
| Метод | «покажу, как проверить до аванса» | «гарантирую нулевой риск» |
| TL;DR | 3–6 строк «Быстрый инсайт» | Копипаст всего лида |
| H2-биты | Чеклист / таблица / «где теряют деньги» | Вода «виды недвижимости» |
| Вердикт секции | Одна фраза: что не сравнивать / что не подписывать | Мотивационный слоган |
| Финал | Предел: проверка ≠ отсутствие суда; дисклеймер юрконсультации | Призыв «покупайте сейчас» |
| CTA | Одна ссылка из tenant-config, после пользы | Ссылки в каждом абзаце |

## Длина бита

- 1 мысль = 1 H2.
- Чеклист: глаголы (запросите, проверьте, зафиксируйте, не подписывайте).
- Таблица: только если Writer дал сопоставимые строки (кто платит, что входит, до какого этапа). Под таблицей — человеческий вердикт, не «смотрите таблицу выше» без смысла.
- География (Тюмень, Мыс, Червишевский тракт, Тобольск): если меняет проверку. Иначе не набивать для SEO.

## Зеркало Дзен

Та же статья, тот же слог. Карточка/H1 не кликбейт и не оценка как факт. Мат и эмодзи не появляются при «адаптации под Дзен».

## Writer vs Sol

- Writer держит смысл и факты.
- Sol переписывает слогом этого файла и `good-outputs.md`.
- После Sol прозу не переписывают ради «ещё живее», кроме возврата Sol при FAIL гейтов слога.
